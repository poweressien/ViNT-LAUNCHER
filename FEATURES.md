# Features (intended scope)

Authoritative per-feature status is in `IMPLEMENTATION_STATUS.md`. This lists what exists in the code.

**Home & apps:** real app discovery, launch via LauncherApps, drawer with sort/search/hidden section, auto-grouped floating groups
(big + small cluster), titles, real badges, dock with search pill, universal search (apps, groups, settings, contacts),
long-press menu (rename, pin, hide, move, change icon, resize, info, uninstall, shortcuts).

**Display engines:** Classic · Floating · Auto-shuffle · Orbital · 3D Shapes (cube, sphere, cylinder, ring, pyramid, multi-layer carousel; OpenGL ES) ·
Holographic · Galaxy · Matrix · Carousel · Timeline · Magnetic · DNA · Liquid · Adaptive. Presets save/apply.

**Studio:** engine & performance, 3D controls, 9 themes + gradients, icon styles/packs/custom icons, wallpapers (image/video/animated; system wallpaper apply),
fonts (built-in + import), motion, layout, gestures, presets, permissions/system.

**System:** notification centre + island + badges, Control Center, lock-screen companion (clearly non-secure), SMS companion, status-bar styling,
AppWidgetHost widgets, gesture engine (incl. shake/tilt), on-device suggestions, onboarding.

**Honest limits:** cannot replace the system status bar or system font; no MMS; no true live-wallpaper service; companion lock screen is not secure.
